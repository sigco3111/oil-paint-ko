# 유화 (Oil paint) — 한국어판

> 원작: [blendi/oil-paint](https://patch.gg/blendi/oil-paint) (Patch) · 코드 MIT / 아트 CC0 1.0
> 이 저장소는 원작자의 허용 라이선스에 따라 제작된 비공식 한국어판입니다. 모든 영광은 원작자 blendi에게 있습니다.

three.js 장면을 두꺼운 유화 붓터치로 그려내는 이펙트 데모입니다. 나뭇잎 하나, 눈송이 하나, 오로라의 빛줄기, 외투의 주름 하나까지 모두 세상에 고정된 붓의 자취라서, 움직여도 물감이 사물 위에 그대로 남아 있습니다.

데모는 두 개의 산책 장면입니다:

- **오로라** — 눈 덮인 가문비나무 사이에서 시작해 온 하늘이 보이는 언덕으로 나와, 능선을 따라 북쪽 오두막까지 걷는 밤길. V 키로 방랑자의 눈으로 볼 수 있고, 오두막 문지방에 서면 자동으로 그 시점이 됩니다. 하늘을 올려다보세요.
- **가을 숲** — 너도밤나무·자작나무·참나무 사이로 난 오솔길을 따라 공터까지 걷는 장면.

## 조작법

| 입력 | 동작 |
|---|---|
| 마우스 클릭 | 마우스로 주위 둘러보기 (포인터 잠금) |
| WASD / 방향키 | 이동 |
| Shift | 달리기 |
| Space | 점프 |
| 마우스 휠 | 시점을 뒤로/앞으로 |
| V | 1인칭 시점 (오로라 장면) |
| H | 조작 안내 숨기기/보이기 |
| 게임패드 | 지원됨 |

## 특징

- 화면에 후처리 필터를 씌우는 방식이 아니라, 모든 사물이 **붓터치(dab)** 하나하나로 그려집니다.
- 색은 빛이 아니라 물감: 사물마다 밝은부분·중간톤·그림자의 세 가지 섞인 색을 가집니다.
- 거리에 따라 붓터치를 크고 적게 그려 원근을 단순화합니다.
- 그림자는 정지된 세계 기준으로 한 번만 그려 붓터치 가장자리가 거칠게 남습니다.
- 오로라·불꽃·촛불처럼 빛나는 것은 덧칠이 아니라 더해지는 붓터치로 그립니다.
- 게임에 붙이는 시작점으로 설계됨: 장면의 사물마다 세 가지 색과 붓터치 방향을 지정해 사용 (`src/oilpaint/`).

## 기술 정보

- three.js 0.186 (WebGL2 전용, WebGPU 미지원), Rapier 물리(Apache-2.0)
- 빌드: `npm install` 후 `npm run build` → `dist/`에 정적 파일 생성
- 데모 다운로드 약 9MB, 저사양은 `?quality=low` 주소 매개변수로 경량화 가능
- RTX 4090·1080p 기준 프레임 약 4.5~4.6ms (원작자 측정)
- PC 키보드·마우스 권장. 각 장면은 하루 중 한 시간대이며, 구역을 벗어나면 시작점으로 돌아갑니다.

## 한국어판 변경 사항
